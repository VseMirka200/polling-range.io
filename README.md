**Избирательный полигон** — интерактивный браузерный тренажёр по основам избирательного права. Проект помогает в игровой форме изучать термины, порядок голосования, права участников выборов и типичные нарушения на избирательном участке.

Приложение размещено как статический сайт GitHub Pages и не требует установки зависимостей, сборки или серверной части.

## Возможности

В тренажёре доступны три игровых режима.

### 🏃 Помоги избирателю

Пользователь отвечает на вопросы о порядке голосования и работе избирательной комиссии.

- несколько вариантов ответа;
- пояснение после выбора;
- ссылки на официальные источники;
- подсчёт правильных ответов;
- постепенное увеличение сложности.

### 🧠 Мемори

Игра на сопоставление избирательных терминов и их определений.

- от 4 до 8 пар карточек;
- случайное перемешивание карточек;
- 6 уровней сложности;
- отдельные уровни с обязательным ограничением времени.

### 🔍 Найди нарушение

Пользователю необходимо определить незаконные или неправильные действия на избирательном участке.

- интерактивный выбор ситуаций;
- мгновенная обратная связь;
- пояснение для правильных и неправильных ответов;
- различное количество нарушений на каждом уровне.

## Дополнительные функции

- 6 уровней сложности для каждого игрового режима;
- дополнительный режим прохождения на время;
- информационная стойка с основными терминами;
- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- управление карточками с клавиатуры с помощью `Enter` и `Пробела`;
- визуальная обратная связь, анимации и таймер;
- ссылки на материалы ЦИК России и РЦОИТ.

## Использование

1. Нажмите кнопку **«ОТКРЫТЬ»** в верхней части README.
2. Выберите один из трёх игровых режимов.
3. Выберите уровень от 1 до 6.
4. При необходимости включите режим **«Играть на время»**.
5. Выполните задания и переходите к следующим уровням.
6. Нажмите кнопку с изображением книги, чтобы открыть справку.
